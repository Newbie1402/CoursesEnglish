# CoursesEnglish
Run backend server:
```
  Run services in docker-compose.yaml
```
Install plugins:
```
  Install plugins Envfile in IntelliJ or other IDE
  Step 1: Paste file .env into folder BE_Courses
  Step 2: Run -> Edit Configurations
  Step 3: Click CoursesApplication -> Tick Enable Envfile
  Step 4: Tick enable .env in the below table 
  Step 5: Click Apply and OK
```
