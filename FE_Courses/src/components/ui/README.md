# UI Components

Chứa các components UI cơ bản có thể tái sử dụng trong toàn bộ ứng dụng.

## Cấu trúc

```
ui/
  button/
  input/
  select/
  card/
  modal/
  table/
  alert/
  badge/
  loading/
```

## Quy tắc

- Mỗi component được tách thành module riêng
- Sử dụng Typescript cho type safety
- Tất cả components phải có PropTypes hoặc TypeScript interface
- Tất cả components phải có documentation và examples
